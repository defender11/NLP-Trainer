# ROADMAP.md

## WebSocket roadmap

`ws.js` остается опциональным и не должен влиять на offline-first режим.

### 1. Remote focus sync

Синхронизация состояния между:

- Mac;
- iPhone;
- iPad.

### 2. Shared focus room

Несколько пользователей:

- запускают Pomodoro одновременно;
- видят общий таймер.

### 3. Voice telemetry

Сервер может:

- логировать прогресс;
- сохранять статистику;
- анализировать usage.
